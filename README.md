# THE VOID — Performance & Recovery Club

Sitio web minimalista con motion graphics. HTML, CSS y JavaScript puro, sin dependencias.

- `index.html` — la página
- `assets/` — logo y fotografías

Para verlo: abre `index.html` en el navegador.

## Créditos de imágenes

- Cabeza de atleta y guerrero herido: The Metropolitan Museum of Art, Open Access (dominio público, CC0).
- Hércules Farnesio: foto de Marie-Lan Nguyen (2011), Wikimedia Commons, licencia CC BY 2.5.
- Escultura de caballo y logo: proporcionados por THE VOID.
